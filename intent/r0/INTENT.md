# Round 0: pacman

Create a pacman game with pixel art, responsive, playable with WASD or the arrow keys.

Constraints for this round:

- One level, one maze, four ghosts, dots and power pellets, lives and a score on screen. No sound, no menu, no leaderboard yet.
- Pixel art drawn on a canvas that scales to the window while keeping its aspect ratio.
- No accounts, no backend, no persistence; a static site is enough.
- Tests on the game loop: movement, wall collision, dot eating, ghost collision, win and lose.
